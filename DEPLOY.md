# Деплой на Netlify и Render

В репозитории подготовлены `netlify.toml` и `render.yaml`. Фронтенд публикуется на Netlify; API, queue worker и PostgreSQL запускаются на Render. Для бесплатного плана API и worker работают в одном web-сервисе. Blueprint включает разрешённый архив данных организаторов и offline-режим LLM.

## 1. Render: API, worker и база

1. Запушьте репозиторий в GitHub/GitLab.
2. В Render выберите **New → Blueprint**, подключите репозиторий с `render.yaml` и создайте ресурсы. Подтвердите тариф PostgreSQL и сервисов.
3. Для `alfa-hack-api` задайте переменную `ALLOWED_ORIGINS` как JSON-массив с origin Netlify, например `["https://имя-сайта.netlify.app"]`. На первом проходе можно временно указать `[]`, а после создания сайта Netlify заменить значение и дождаться redeploy API.
4. Проверьте `https://<имя-api>.onrender.com/health/ready` — ожидается HTTP 200.

Render передаёт API внутренний `DATABASE_URL`; миграции и импорт архива организаторов выполняются перед запуском. Queue worker работает в том же бесплатном web-сервисе. Секреты не нужно помещать во frontend.

## 2. Netlify: frontend

1. Создайте сайт через **Add new site → Import an existing project** и выберите тот же репозиторий. Netlify подхватит `netlify.toml`: каталог сборки `frontend`, команда `pnpm build`, публикация `frontend/dist`.
2. В настройках сайта → **Environment variables** добавьте `VITE_API_BASE_URL` со значением `https://<имя-api>.onrender.com` (без завершающего `/`).
3. Запустите новый deploy. SPA-переходы настроены правилом перенаправления в `netlify.toml`.
4. Убедитесь, что origin сайта Netlify в точности указан в `ALLOWED_ORIGINS` Render. Для preview deploy можно отдельно добавить его URL, если он должен обращаться к API.

## Данные и ограничения

В форк включён `ml/data.zip` с файлами организаторов, которые разрешено использовать в прототипе. Docker при сборке проверяет пути архива и распаковывает данные в `/app/ml/data`; bootstrap импортирует CSV и банковские материалы в PostgreSQL. Для лимита Free Postgres сохраняются до трёх крупнейших платёжных наблюдений на компанию в роли плательщика и получателя; исходный полный CSV остаётся в архиве. Доли связей рассчитаны по сохранённой выборке. Миграция и импорт запускаются при старте контейнера параллельно с API, чтобы порт открывался сразу; обработчик очереди стартует после импорта. Не добавляйте в архив секреты, `.env` или данные вне разрешённого набора. Free Postgres ограничена 1 ГБ и удаляется через 30 дней. Free web-сервис засыпает при простое; очередь обрабатывается, пока сервис активен.
