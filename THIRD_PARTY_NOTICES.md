# Сторонние компоненты и данные

Версии Python-зависимостей и хеши дистрибутивов зафиксированы в uv.lock.
Лицензии и copyright notices поставщиков сохраняются в установленных пакетах.

| Компонент | Назначение |
| --- | --- |
| Python 3.12 | Среда исполнения |
| FastAPI / Starlette | HTTP API и OpenAPI |
| Pydantic / pydantic-settings | Контракты и настройки |
| Uvicorn | ASGI-сервер |
| psycopg / psycopg-pool / psycopg-binary | PostgreSQL; binary включает компоненты libpq |
| pandas / NumPy | Профилирование компаний и аудит CSV |
| HTTPX | Клиент разрешённого LLM endpoint и HTTP-проверки |
| LLM хакатона | Только Gemma 4 26B A4B, GLM-5.3-Flash, Qwen3.6 35B A3B, DeepSeek-V4.1-Flash, Qwen3-VL-30B-A3B-Instruct, Kimi-K2.6; runtime ограничивает выбор фиксированным allowlist |
| Публичные RSS/Atom-источники | Используются только после явного указания HTTPS URL оператором в `NEWS_FEED_URLS`; права использования и пригодность источника проверяет оператор |
| PostgreSQL | Хранилище и долговечная очередь заданий |
| pytest / Ruff | Тестирование и статические проверки |
| uv | Фиксация и установка зависимостей |
| Docker / Compose | Конфигурация запуска |

ML-код из папки news_analytics 2 предоставлен командой пользователя, перенесён
с сохранением исходных модулей и тестов и изменён при интеграции. Условия
использования исходного ML-кода определяет правообладатель этого пакета.

Датасеты юридических лиц, платежей, связей физлиц и Markdown-аналитика
Альфа-Банка — предоставленные материалы кейса. Они остаются приватными,
не включаются в Docker image и исключены из текущего Git-индекса.
В старой истории репозитория материалы всё ещё присутствуют.

Публичные профили DEMO_* и три новости seed-demo созданы как синтетические
фикстуры. Они не являются реальными клиентами или публикациями СМИ.
Исходные JSON-примеры из ML-пакета также демонстрационные; не использовать
их адреса rbc.ru/news1 и аналоги как подтверждённые первоисточники.

Смоделированные/неподключённые интеграции: offline LLM (правила, не вызов
модели), GLiNER (в API выключен), Neo4j и Qdrant (адаптеры сохранены, но сервис
их не использует), банковские продукты (реальные заявки не создаются).
LangGraph не входит в runtime-зависимости и не используется для оркестрации.
Live-режим использует OpenAI-совместимый HTTP-протокол выбранного разрешённого
организаторами провайдера; никакой сторонний AI endpoint не задан по умолчанию.
