# Спецификация экранов: Вход и регистрация пользователя (registration_design.md)

## 1. Контекст, назначение и философия дизайна
Спецификация описывает единую входную группу (шлюз авторизации и онбординга) в корпоративное приложение новостной аналитики и мониторинга рисков **«Альфа-Бизнес»**. 

Интерфейс спроектирован по принципам дизайн-системы **Core Components (Альфа-Банк)** с компоновкой в виде сплит-карточки (Horizontal Split Card) на основе композиционного референса `изображение.png`.

### Ключевые цели и принципы:
- **Бесшовный доступ**: Приоритетное предложение входа и регистрации через корпоративный профиль **Альфа-ID / Альфа-Бизнес** в один клик без ручного ввода паролей.
- **Единый сплит-тайлинг**: Монолитная карточка разделена на левую брендово-информационную колонку и правую функциональную форму с переключением состояний («Вход» ↔ «Регистрация») без перезагрузки страницы.
- **Сбор контекста для AI-аналитики**: В процессе регистрации собираются отрасль компании, должность сотрудника и размер штата, что позволяет калибровать веса риск-моделей в ленте новостей под конкретный профиль пользователя.
- **Безопасность банковского класса**: Визуальные индикаторы сквозного шифрования, протокола Банка России (ГОСТ Р 34.12-2015, TLS 1.3) и двухфакторной аутентификации (2FA).

## 2. Архитектура макета (Layout & Grid)

### 2.1. Глобальная структура страницы
- **Фон рабочей области (`surface`)**: Нейтральный светлый оттенок `#F8F9FA`.
- **Шапка шлюза (Header)**:
  - Слева: Фирменный логотип «Альфа-Бизнес» с бейджем «Интеллект & Мониторинг».
  - По центру: Индикатор защищенного корпоративного шлюза авторизации и версия сессии.
  - Справа: Статус протокола TLS 1.3 и кнопка обращения в корпоративную поддержку.
- **Центральный сплит-контейнер (Card Container)**:
  - Максимальная ширина: `1120px`, автоматическое выравнивание по центру (`margin: 0 auto`).
  - Фон: `#FFFFFF`, скругление углов: `20px` (`border-radius: 20px`), деликатная тень `box-shadow: 0 12px 32px rgba(0, 0, 0, 0.06)`.
  - Внутреннее разделение: двухколоночная сетка `grid-template-columns: 420px 1fr` (или `40% / 60%`).
- **Подвал шлюза (Footer)**:
  - Копирайт АО «АЛЬФА-БАНК», номер генеральной лицензии ЦБ РФ №1326.
  - Служебные ссылки: Конфиденциальность, Безопасность данных, Регламент сервиса.
  - Нижняя сервисная строка: Скорость отклика шлюза (< 0.18 сек), кластер мониторинга, статус штатного режима работы.

## 3. Спецификация левой колонки (Бренд и ценностное предложение)

- **Фон**: Глубокий премиальный графитовый градиент (`#1F2229` с легким радиальным рассеиванием к `#14161A`).
- **Внутренние отступы**: `40px` (`p-10`).
- **Цвет текста**: Контрастный белый `#FFFFFF` и нейтральный приглушенный `#9CA3AF`.
- **Элементы структуры**:
  1. **Шапка бренда**:
     - Фирменная красная плашка-логотип с белой литерой **«А»** (высота 44px, радиус 10px).
     - Текстовый блок: «Альфа-Бизнес / ИНТЕЛЛЕКТ & МОНИТОРИНГ».
  2. **Статус-бейдж**:
     - Капсула `Tag/Badge` с молнией: «⚡ Единый профиль компании» (полупрозрачный фон `rgba(255,255,255,0.08)`).
  3. **Заголовок и ценность**:
     - Заголовок H1/H2: *«Интеллектуальная аналитика и риск-мониторинг для вашего бизнеса»* (24–26px, font-weight: 700, line-height: 1.3).
     - Лид-абзац: *«Оперативный контроль контрагентов, предиктивный аудит и доступ к корпоративным инструментам Альфа-Банка»* (14–15px, line-height: 1.5, цвет `#9CA3AF`).
  4. **Блок преимуществ корпоративного доступа** (в режиме регистрации):
     - Список с фирменными красными иконками (`List`):
       - Персональная калибровка AI-аналитики под отрасль вашей компании.
       - Автоматический скоринг надежности контрагентов по реестрам ЦБ.
       - Готовые сценарии защиты от валютных и налоговых рисков.
       - Защита стандартов безопасности Банка России ГОСТ Р 34.12-2015.
  5. **Нижний блок гарантии безопасности**:
     - Иконка щита, подпись *«Защищено стандартами Банка России: Двухфакторная верификация, сквозное шифрование и строгий банковский регламент»* (12px, цвет `#8C959F`).

## 4. Спецификация правой колонки (Форма входа и регистрации)

- **Фон**: Белый `#FFFFFF`.
- **Внутренние отступы**: `40px 48px`.
- **Элементы шапки формы**:
  - В правом верхнем углу: Компактный капсульный переключатель языка `RU / EN` (по референсу `изображение.png`).
  - По центру: Нейтральная круглая иконка профиля пользователя (диаметр 52px, фон `#F3F4F6`) с зеленым бейджем готовности к авторизации.
  - Заголовок H2: *«Вход в кабинет»* или *«Регистрация в кабинете»* (22px, font-weight: 600, цвет `#1F2229`).

### 4.1. Единый таб-переключатель (`@alfalab/core-components/tabs`)
- Капсульный переключатель режима:
  - Таб 1: **«Вход»**
  - Таб 2: **«Регистрация»**
- Фоновая подложка переключателя: `#F3F4F6`, скругление `12px`, padding `4px`.
- Активный таб: белый фон `#FFFFFF`, тень `0 2px 6px rgba(0,0,0,0.06)`, скругление `10px`, цвет текста `#1F2229`, font-weight: 600.
- Неактивный таб: прозрачный фон, цвет `#6B7280`.

## 5. Спецификация состояний формы

### 5.1. Экран «Вход в кабинет» (`SCREEN_4`)
1. **Быстрый вход через банк (Fast Primary Auth)**:
   - Кнопка `Button view="accent"`: **«Войти через Альфа-ID Бизнес»**
   - Цвет: фирменный красный `#EF3124` (Pantone 1795CU), высота `48px`, радиус `12px`, иконка литеры «А».
2. **Разделитель**:
   - Лаконичная линия с центрированной подписью: *«ИЛИ ЧЕРЕЗ УЧЕТНУЮ ЗАПИСЬ»* (12px, uppercase, цвет `#8C959F`).
3. **Поля ввода Core Components (`Input`)**:
   - **Рабочий e-mail**: лейбл «Рабочий e-mail», иконка почты в левом слоте, подсказка справа «корпоративная почта».
   - **Пароль доступа**: лейбл «Пароль доступа», маскирование символов (`••••••••••••`), иконка «глаз» для отображения/скрытия пароля, ссылка «Забыли пароль?» фирменного красного цвета.
4. **Опции и кнопка действия**:
   - Чекбокс: *«Запомнить устройство на 30 дней»* + индикатор *«✓ 2FA Активен»*.
   - Кнопка действия: **«Войти в систему →»** (`Button view="primary"` / цвет Process Black `#1F2229`, высота 48px, радиус 12px, текст `#FFFFFF`).
5. **Поддержка**:
   - Строка быстрой помощи: *«Возникли трудности? Поддержка корпоративных клиентов 8 800 100 77 33»*.

---

### 5.2. Экран «Регистрация в кабинете» (`SCREEN_2`)
1. **Быстрая регистрация через банк**:
   - Кнопка `Button view="accent"`: **«Регистрация через Альфа-Бизнес»** (высота 48px, радиус `12px`).
   - Позволяет моментально импортировать верифицированные данные организации из банка без ручного ввода.
2. **Разделитель**:
   - Линия с подписью: *«ИЛИ ЗАПОЛНИТЕ ДАННЫЕ ВРУЧНУЮ»*.
3. **Поля ввода и вопросы онбординга**:
   - **ФИО сотрудника**: `Input` (полноширинное поле, плейсхолдер с примером).
   - **Двухколоночный ряд 1:1 (Компания и отрасль)**:
     - Слева: **Компания / ИНН \*** (`Input`, поле для 10-значного ИНН организации).
     - Справа: **Отрасль бизнеса**: выпадающий список `Select` (варианты: «Оптовая торговля», «Логистика и ВЭД», «Производство», «IT и Телеком», «Строительство»).
   - **Двухколоночный ряд 1:1 (Должность и штат)**:
     - Слева: **Должность в компании \*** (`Input` / `Select`, значение: «Финансовый директор (CFO)», «Генеральный директор», «Главный казначей»).
     - Справа: **Размер штата**: выпадающий список `Select` («до 50 сотрудников», «50–250 сотрудников», «более 250 сотрудников»).
   - **Двухколоночный ряд 1:1 (Контакты)**:
     - Слева: **Рабочий e-mail \*** (`Input` с валидацией корпоративного домена).
     - Справа: **Рабочий телефон** (`Input` с маской `+7 (999) 000-00-00`).
   - **Пароль для входа \***:
     - Поле с индикатором «✓ Высокая надежность», кнопкой показа символов и подсказкой о требованиях безопасности.
4. **Юридическое согласие**:
   - Кастомный чекбокс: *«Соглашаюсь с Регламентом сервиса и условиями безопасности Банка России»*.
5. **Целевая кнопка**:
   - Кнопка `Button`: **«Зарегистрироваться в системе →»** (Process Black `#1F2229`, радиус `12px`).
6. **Быстрый переход**:
   - Ссылка: *«Уже зарегистрированы? Войти»* (красный `#EF3124`).

## 6. Компоненты Core Components (Альфа-Банк)

1. **Button (`@alfalab/core-components/button`)**:
   - `view="accent"`: фирменный красный `#EF3124` (Pantone 1795CU), текст `#FFFFFF`, высота 48px, радиус скругления `12px`, полужирный шрифт.
   - `view="primary"`: графитовый черный `#1F2229` (Process Black), текст `#FFFFFF`, высота 48px, радиус `12px`.
   - `view="text"` / Ссылки: акцентный красный ховер, отсутствие подчеркивания в покое.
2. **Input (`@alfalab/core-components/input`)**:
   - Высота: `44px` (`size="m"`).
   - Фон: нейтральный `#F3F4F6` в покое или чистый белый `#FFFFFF` с рамкой `1px solid #E5E7EB`.
   - Скругление углов: `10px`.
   - Фокус: граница `#EF3124`, внешнее деликатное свечение `box-shadow: 0 0 0 2px rgba(239, 49, 36, 0.15)`.
3. **Select (`@alfalab/core-components/select`)**:
   - Высота `44px`, радиус `10px`, правый слот под стрелку-шевроном (`ChevronDown`).
4. **Tabs (`@alfalab/core-components/tabs`)**:
   - Двухпозиционный переключатель режимов «Вход / Регистрация» в виде монолитной капсулы.
5. **Checkbox (`@alfalab/core-components/checkbox`)**:
   - Фирменный красный фон при активации (`#EF3124`), белая иконка галочки, скругление `4px`.
6. **Badge & StatusTag (`@alfalab/core-components/badge`)**:
   - Индикаторы безопасности, протоколов ЦБ и статуса надежности пароля.
