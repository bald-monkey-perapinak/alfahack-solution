# Дизайн-система новостной аналитики: Core Components (Alfa-Bank)

## 1. Назначение и контекст

Интерфейс корпоративной новостной аналитики и детального AI-анализа новостей для клиентов экосистемы «Альфа-Бизнес».

Приложение предназначено для мониторинга макроэкономических новостей, регуляторных изменений и рыночных трендов с AI-анализом влияния на показатели бизнеса компании, её договоры и финансовые инструменты.

Документ объединяет описание ленты новостей, страницы детального анализа и гибридной системы контейнеров ленты (Hybrid Container Tiling). Общие компоненты и визуальные правила описаны один раз. Новые правила контейнеров уточняют размеры и компоновку карточек в зависимости от количества материалов в блоке.

## 3. Общие компоненты Core Components

### 3.1. Button

Указанный импорт: `@alfalab/core-components/button`.

#### Основная кнопка — Accent

- Применение: «Анализировать», «Открыть анализ →», «Анализ», «Анализ →», действия подтверждения.
- Указанные свойства: `view="accent"`; `size="m"` для контейнеров на 1–2 новости и `size="s"` для контейнеров на 3–4 новости. В компактных карточках также допускается текстовая ссылка перехода к анализу.
- Фон: `#EF3124`; текст: `#FFFFFF`.
- Для основного размера `m`: высота `40px`, горизонтальный padding `20px`. Радиус: `12px`; параметры размера `s` уточняются по выбранной версии библиотеки.
- Насыщенность шрифта: `500`.
- Состояния: default, hover, active, disabled.
- Hover: затемнение фона до `#D3271B`.
- Disabled: `opacity: 0.4`.

#### Второстепенная кнопка — Secondary / Ghost / Text

- Применение: «Подробнее ↓», «Свернуть ↑», «← Вернуться к ленте», «Экспорт в PDF», переключатели периодов.
- Указанные варианты: `view="secondary"` или `view="text"`; Ghost используется как описание визуального стиля.
- Фон: прозрачный либо `#FFFFFF` с границей `1px solid #E5E7EB`.
- Hover: `#F3F4F6`.
- Текст: `#1F2229`; радиус: `12px`.
- Для раскрытия: справа располагается шеврон вниз / вверх.

### 3.2. Collapse / Accordion

Указанный импорт: `@alfalab/core-components/collapse`.

Назначение: прогрессивное раскрытие подробного контента в крупных карточках новостей и блоках анализа для быстрого сканирования содержимого. В ленте Collapse используется в контейнере на 1 новость (Hero); для контейнеров на 2–4 новости раскрытие внутри карточки не предусмотрено новыми правилами.

Анатомия:

- Trigger: кнопка «Подробнее ↓» / «Свернуть ↑» в нижней панели действий карточки.
- При нажатии переключается состояние и поворачивается шеврон на `180°`.
- Content Container: подробный текст новости и плашка ключевого вывода аналитиков.

Состояния, указанные в исходном описании:

| Состояние | Параметры |
| --- | --- |
| `collapsed`, по умолчанию | `max-height: 0; opacity: 0; overflow: hidden; pointer-events: none` |
| `expanded` | `max-height: 1200px; opacity: 1; pointer-events: auto` |

Указанная анимация:

```css
transition:
  max-height 0.35s cubic-bezier(0.4, 0, 0.2, 1),
  opacity 0.25s ease,
  margin 0.3s ease;
```

Оформление содержимого:

- Размер текста: `16px`; line-height: `1.5`; цвет: `#374151`.
- `padding-top: 16px`.
- `margin-top: 16px`.
- `border-top: 1px solid #F3F4F6`.

Способ анимации следует согласовать с возможностями компонента. При реализации необходимо проверить длинный контент: фиксированный `max-height: 1200px` не должен обрезать текст. Приведённый CSS сам по себе не гарантирует аппаратное ускорение.

### 3.3. IconButton

Указанный импорт: `@alfalab/core-components/icon-button`.

- Применение: избранное, шеринг, закрытие модальных окон, поиск.

- Указанный размер: `size="m"`; в исходниках предусмотрены `36×36px` / `40×40px`.
- Радиус: `8–10px`.
- Цвет иконки: `#8C959F`.
- Активное избранное: `#EF3124`, закладка с заливкой.

### 3.4. Input

Указанный импорт: `@alfalab/core-components/input`.

- Применение: поиск по новостям, компаниям и тематикам в шапке ленты; фильтрация аналитических отчётов.
- Указанный размер: `size="m"`; высота: `40px`.
- Радиус: `10px`.
- Слева: иконка поиска, обозначенная в исходниках как `Magnifier`.

- Граница: `1px solid #E5E7EB`.

### 3.5. Tabs

Указанный импорт: `@alfalab/core-components/tabs`.

- В исходном ряду фильтров также предусмотрено «Только срочные».
- Переключатели периодов и вкладок анализа.

Оформление:

- Pill / Capsule, радиус `20px`.
- Активный таб: `#212121` с белым текстом либо `#EF3124` для акцентных фильтров.
- Неактивный таб: фон `#F3F4F6`, текст `#1F2229`.

### 3.6. Link

Указанный импорт: `@alfalab/core-components/link`.

- Применение: первоисточники и внешние нормативные документы.

- Указанное свойство: `view="default"`.
- Цвет: `#1F2229`.
- Иконка внешнего перехода в исходниках обозначена как `ExternalLink`.
- Hover: подчёркивание.
- Первоисточник открывается во внешней вкладке для всех форматов контейнеров.

## 4. Экран ленты новостей

### 4.1. Поиск и навигация

- Поиск по новостям, компаниям и тематикам в шапке ленты.
- Переключатель «Все новости (128)» / «Избранное» с количеством материалов; `128` — пример из макета.
- Горизонтальный ряд тем и фильтр «Только срочные».
- Основное содержимое — лента адаптивных контентных контейнеров, каждый из которых объединяет от 1 до 4 связанных новостей выпуска или темы.

### 4.2. Концепция Hybrid Container Tiling

Количество материалов в тематическом блоке определяет сетку, формат карточек и визуальную плотность. Полноразмерная карточка применяется для одного материала; для нескольких используются равные либо асимметричные композиции.

| Количество новостей | Вариант | Компоновка | Основное действие |
| --- | --- | --- | --- |
| 1 | Hero News | Одна колонка на всю ширину контентной зоны | «Открыть анализ →», размер `m` |
| 2 | Duo Grid | Две равные колонки, Medium Card | «Анализ», размер `m` |
| 3 | Trio Asymmetric | Главная карточка слева, две компактные справа | «Открыть анализ →» / компактный переход, размер `s` |
| 4 | Quartet Grid | Сетка `2×2`, горизонтальные Small Card | «Анализ →», размер `s` или текстовая ссылка |

Закладка располагается справа вверху каждой карточки. Для каждого материала сохраняется доступ к первоисточнику во внешней вкладке. Метки типа новости и оценки используют общие компоненты Badge / Tag.

### 4.3. Контейнер на 1 новость — Hero News

**Сценарий:** ключевое событие выпуска: срочная новость, решение ЦБ, фундаментальный регуляторный отчёт.

**Сетка:** одна колонка, `100%` ширины контентной зоны.

Порядок блоков:

1. **Метаданные.** Логотип или название источника («Коммерсантъ», «РБК», «Ведомости»), время через точку-разделитель, метка типа новости. Справа — оценка и закладка.
2. **Заголовок.** `20–22px`, semi-bold, визуальный уровень H1/H2. Семантический уровень выбирается по иерархии страницы.
3. **Изображение.** Панорамное фото высокого разрешения на ширину карточки. Соотношение сторон около `16:7` или `16:9`, ориентировочная высота `320–360px`, радиус `12px`.
4. **Полная панель действий.** «Открыть анализ →» через Button Accent размера `m`; «Подробнее ↓» / «Свернуть ↑» через текстовую кнопку; ссылка «Первоисточник ↗»; шеринг. Закладка остаётся в верхней строке.
5. **Collapse.** Подробный текст и плашка «Ключевой вывод аналитиков» с левой акцентной чертой `#EF3124` и фоном `#F9FAFB`.

Поведение раскрытия:

- По умолчанию подробный контент скрыт.
- Нажатие «Подробнее ↓» раскрывает содержимое в этой же карточке.
- Подпись меняется на «Свернуть ↑», шеврон поворачивается.
- Повторное нажатие скрывает подробности.
- Переход к анализу выполняется отдельной основной кнопкой.
- Параметры анимации и оформления Collapse описаны в разделе 3.2.

### 4.4. Контейнер на 2 новости — Duo Grid

**Сценарий:** две равнозначные важные новости в одной теме, например «Макроэкономика» или «Финансы и Банки».

**Сетка:** `grid-template-columns: repeat(2, 1fr)`, gap `20px`.

Каждая Medium Card включает:

1. Метаданные: источник, время, тип новости, оценка `4/5` как пример отображения и закладка.
2. Заголовок `17–18px`, semi-bold, ограничение высоты до `2–3` строк.
3. Изображение: соотношение около `16:10`, высота `180–200px`, радиус `10px`.
4. Краткую аналитическую выжимку на `2–3` строки, размер текста `14–15px`.
5. Панель действий: «Анализ» через Button Accent размера `m`, ссылка на первоисточник и шеринг.

### 4.5. Контейнер на 3 новости — Trio Asymmetric

**Сценарий:** одно доминирующее событие и два сопутствующих или контекстных материала.

**Сетка:** две колонки с пропорцией `1.4fr 1fr`; слева главная карточка, справа вертикальный стек из двух карточек. Между колонками — `20px`, между карточками правого стека — `16px`.

**Главная карточка — Primary Lead:**

- Высота совпадает с высотой правого стека в двухколоночной композиции.
- Заголовок `18–19px`, semi-bold.
- Полноценное фото высотой около `220px`.
- Вводный абзац анализа.
- Кнопка «Открыть анализ →» размера `s` и ссылка на источник.
- Закладка справа вверху.

**Второстепенные карточки — Secondary Pair:**

- Горизонтальная компоновка: текст слева, миниатюра справа.
- Миниатюра: `100×80px`, радиус `8px`.
- Компактный переход к анализу: Button размера `s` либо текстовая ссылка.
- Доступ к первоисточнику и закладка справа вверху.

### 4.6. Контейнер на 4 новости — Quartet Grid

**Сценарий:** оперативная подборка новостей второго плана, обзор рынков или дайджест.

**Сетка:** `2×2`, `grid-template-columns: repeat(2, 1fr)`, gap `16px`.

Каждая Small Card использует горизонтальную компоновку:

- Слева — миниатюра `120×86px`.
- Справа — метаданные, заголовок и быстрый переход «Анализ →».
- Действие анализа: размер `s` либо текстовая ссылка.
- Закладка справа вверху; первоисточник доступен во внешней вкладке.

Компактный формат предназначен для быстрого просмотра большого количества материалов с меньшей высотой ленты.

### 4.7. Общие правила сетки и отступов

| Параметр | Значение |
| --- | --- |
| Внутренний отступ контейнера или карточки | `20–24px` |
| Радиус внешнего контейнера и карточек | `12px` |
| Между крупными контейнерами ленты | `24px` |
| Duo: между карточками | `20px` |
| Trio: между основной и правой колонками | `20px` |

Размеры изображений с символом «около» и диапазоны высот являются ориентирами из макета. Окончательные правила соотношения сторон и кадрирования нужно согласовать с шириной контейнеров.

## 6. Вопросы для уточнения перед реализацией

Этот раздел фиксирует неоднозначности исходных текстов и дополнения Hybrid Tiling и не изменяет утверждённый внешний вид.

1. **Версия и API Core Components.** Проверить импорты, допустимые `view`, размеры и соответствие указанным пиксельным значениям; выбрать реальные иконки из системы.
2. **Рейтинг достоверности.** Определить методику, источник и единый формат показателя `4/5` / `4.9/5`; не использовать числа из макета как реальные оценки.
3. **Шрифт.** `Inter / system-ui` явно указан для графика; закрепить основной шрифт всего приложения.
4. **Краткое описание в карточке.** Для Duo предусмотрена выжимка, для Primary Lead — вводный абзац. Для Hero краткое описание в свёрнутом состоянии не задано; решить, нужно ли его добавить.
5. **Основное действие.** Определить условия отображения «Анализировать» и «Открыть анализ», а также состояния загрузки и ошибки анализа.
6. **Фильтры.** Уточнить возможность выбора нескольких тем, сочетание с поиском и периодом; определить, работает ли «Только срочные» независимо от выбранной темы.
7. **Расчёты и виджеты.** Определить источники данных, формулы, даты актуальности, обработку отсутствующих данных и отделение факта от прогноза.
8. **Состояния и адаптивность.** Не детализированы загрузка ленты, пустые результаты, ошибки, точки перестроения Duo / Trio / Quartet и порядок карточек на узком экране; их нужно согласовать. Равная высота главной карточки и правого стека относится к двухколоночному Trio.
9. **Размеры и варианты.** Выбрать окончательные размеры IconButton, вариант активных табов и остальные значения, указанные диапазоном или через «/».
10. **Длинный контент и таблица.** Проверить отсутствие обрезания раскрытого текста и доступность всех столбцов при ограниченной ширине.
11. **Группировка и порядок новостей.** Определить, кто формирует тематические контейнеры, выбирает главную новость для Trio и разбивает группы больше четырёх материалов. Поведение пустого контейнера также не задано.
12. **Изображения и обрезка текста.** Определить fallback при отсутствии фото, кадрирование при разных ширинах, окончательный радиус миниатюры Quartet и способ доступа к полному заголовку при ограничении строк в Duo.
13. **Приоритет правил.** Для ленты размеры и расположение элементов выбираются по варианту контейнера из раздела 4. Общие значения раздела 3 применяются там, где вариант не задаёт уточнения.
